# Contributing

This is a personal project, but I'm happy to hear from you if you use it too.

- **Found a bug or want a feature?** Open an issue — even a rough one is welcome.
- **Have a fix or improvement?** Pull requests are welcome. No formal process — just open one and I'll take a look.

A few things that'll make a PR easier to review:

- Keep it focused on one change.
- Follow the existing structure — see the "Adding a new command" section in the [README](README.md) and the architecture notes in [CLAUDE.md](CLAUDE.md).
- Note any platform you tested on (Windows/Linux), since the dispatcher is meant to work identically on both.

No CLA, no style guide beyond "match what's already there." If in doubt, just ask in the issue/PR.
